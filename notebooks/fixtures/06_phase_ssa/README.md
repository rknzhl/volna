# Синтетические данные для ноутбука 06

Два входных набора для [ноутбука 06](../../06_phase_ssa.ipynb) созданы
генератором [generate_fresh_phase_fields.py](../../../code/lag_ssa/generate_fresh_phase_fields.py).

Каждый файл NPZ содержит только наблюдения: `Y` — показания десяти датчиков
в 4800 отсчётах, `s` — координаты датчиков, `t` — порядок отсчётов.

- `fresh_r2_irrational_travelling_1d.npz`: датчики на отрезке.
- `fresh_r2_primitive_cover6.npz`: датчики на плоскости.

Файлы скопированы без изменений из входных записей прежнего расчёта.
Истинные фазы, частоты и другие данные для оценки генератора сюда не включены.
